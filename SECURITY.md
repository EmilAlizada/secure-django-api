# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Report security concerns privately to:

**alizadaemil404@gmail.com**

Include:

- affected endpoint or component
- security impact
- safe reproduction steps
- suggested mitigation, if known

## Scope

Application code, authentication and authorization logic, API behavior, container configuration, CI workflows, and dependency configuration are in scope.

This is a portfolio / learning project and is not operated as a production public service.

Do not test infrastructure or accounts that you do not own or have explicit authorization to assess.
